Contributing to OSS-Practice

Welcome! This repository is for practising the open source workflow.

How to contribute
Open an issue that describes the problem you found.
Fork this repository.
Create a new branch for your change (never work on main).
Make a small, focused change.
Commit with a clear message and a sign-off (git commit -s).
Push the branch to your fork and open a Pull Request.
In the description write "Fixes #<issue number>".
Respond politely to review comments.
Rules
One Pull Request = one change.
Do not add phone numbers, emails or other personal details.
Be respectful in every comment.
